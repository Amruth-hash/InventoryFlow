# InventoryFlowOfMachineSpares
Overview

This project is an Inventory Control System designed to manage machine spare parts in an efficient and organized way. It helps track available stock, update inventory when items are added or used, and ensures that spare parts are always available when required for maintenance.

Objective

The main objective of this system is to reduce manual errors in tracking spare parts and to maintain proper stock levels of machine components used in industries or workshops.

Features
Add new spare parts to inventory
Update quantity when parts are used or received
Delete obsolete or unused spare parts
Search for specific machine components
Display current stock details
Alert when stock is low (optional feature)
Working

The system maintains a list of machine spare parts with details like:

Part ID
Part Name
Quantity Available
Supplier Information

Whenever a spare part is issued for maintenance, the quantity is reduced. When new stock arrives, it is added to the existing inventory. This ensures real-time tracking of all components.

Advantages
Reduces manual tracking work
Improves accuracy in inventory management
Saves time during maintenance operations
Prevents shortage of important spare parts
Conclusion

This system helps in maintaining proper control over machine spare parts and ensures smooth operation in industries by avoiding delays due to lack of components.
